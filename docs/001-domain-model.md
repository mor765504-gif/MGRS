# 001 · 换个窗口，怎么算还在做同一件事？

[首页](../README.md) · [导读目录](README.md)

比如昨天你把三份场地报价发给秘秘，让它算场活动要花多少钱。今天你在另一个窗口想起来，「对了，布置费也算上」。它要是回一句「请把三份报价发给我」，你可能都懒得接着说了。报价昨天给过了，场租也算过了，现在只是想多算一项而已。

所以我想给这场活动留一份能接着做的预算。你在哪个窗口来问都行，秘秘想换个 Agent 帮忙算也行。大家找得到**同一项任务**，就能看见原来怎么算的，还有你今天加的那句话。

<a id="改一句要求之前的工作还算数吗"></a>

## 布置费加进来，哪里要重算？

昨天记下的场租还用得上。加上布置费，三家的总价得重算，原来最便宜的那家也未必还是最便宜。有一家从头到尾没提布置费，秘秘在这里留一句「这家还要问」就好。填个零上去，我还以为人家答应免费帮我布置了。

这就是我把要求、材料和结果分开留的原因。你可以改要求，人家发来的三份报价还是那三份。以后再打开旧表，应该能看出来上面那几个总价算的只是场租。下一位接手的人也知道要去问哪一家。[任务与交接](../MGRS.md#collaboration)

还有个问题。假设你既用秘秘管自己的事，又用它帮社团办活动。算预算的 Agent 可以看你交给社团的三份报价，你的个人账户里有些什么，它用不着知道。你前后找的是同一个秘秘，也得让它分得清哪些资料是你交给社团用的。[身份与资料范围](../MGRS.md#extensions)

那家场地一直不回怎么办？如果你只是想看看大概要花多少，先把知道的费用加起来，再估几个数让你比较，也能帮上忙。可如果你要拿这张表去订场地，布置费到底收多少还得问人家。到这里，秘秘能不能先换个做法，跟你准备拿结果去干什么有关系。[少一份报价时怎么办](OPEN-QUESTIONS.md#q01)
