## 第十二条 · 多端协同与会话内 GenUI 契约

### 12.1 多入口回读同一项工作的权威记录

用户可从 Mac、Web 或其他获准接入的客户端发起指令、查看进度或接管操作。各端沿可信会话和对象标识读取相同来源。Hermes 保留会话，Orchestration 维护受管任务，Core 确认业务对象与持久控件版本。主会话交回成果与需要用户决定的事项，Workshop 展开节点、尝试、依赖与回执。

- 界面呈现的状态必须直接映射后端真实状态（区分 `unavailable`、`unconfigured`、`unauthorized`、`pending`、`running`、`unknown-effect`、`verified`、`delivered` 与 `stale`），并附带权威来源、版本号与最后观测时间。
- “界面上显示绿色已发送”或“卡片进度条走满”均不构成客观完成证据；一切业务状态变更必须以宿主登记的真实执行回执为准。

### 12.2 会话内 GenUI 卡片的三态交互契约

会话内 GenUI 通过结构化卡片、表格和控件呈现成果，用户可以在阅读过程中筛选、调整并继续协作。宿主与客户端按内容块、控件和动作分别判断三项就绪条件。

1. **可呈现（`render_ready`）**。当前内容已绑定对应会话，结构可安全呈现时，客户端逐块显示。尚未闭合的结构保留占位，生成中、已验收与已交付各自有明确的状态依据。
2. **可本地交互（`local_interactive`）**。控件声明闭合，取值范围、选项及依赖有效后，用户即可拖动、选择或编辑，此时其余回答仍可继续生成。草稿关联消息、内容代次和控件身份。后续文本和迟到回执到达时，客户端保留较新的本地编辑；刷新时从 Core 恢复已确认值。
3. **可提交动作（`action_ready`）**。原生响应成功结束，可信宿主核对最终消息、已确认内容及控件版本后，才接受该消息上的权威动作提交。提交绑定用户点击时所见的目标、相关编辑及版本，宿主复核当前身份、授权与动作前提。动作依赖特定任务、上游结果或产物版本时，还需校验相应的任务合同；修改任务要求走 `amend_task` 的预期版本检查。版本冲突时回读最新状态并定位受影响控件，由用户处理仍有歧义的改动。

复制内容或在本地筛选可直接完成。保存控件值使用现有 Core 状态接口，按服务确认的版本更新；发起追问沿用原生会话入口；业务写入以实际操作与回执为据，非幂等操作携带稳定的请求标识。已授权的常规动作直接推进，资金支付和用户保留的最终操作按 [第七条](07-tools-and-effects.md#mgrs-7) 交由本人接管。GUI 是 Agent 操作外部软件的执行能力，GenUI 是用户审阅与操作秘秘成果的会话界面。[交付与 GenUI 示例](../parts/05-evidence-and-delivery.md#part-5)

### 12.3 管理视图的读写边界

| 视图 | 展示与操作的权威依据 |
| --- | --- |
| Memory 抽屉 | 展示当前投影、来源、预算及省略依据。用户纠正或撤回事实时，经 Core 原有写入接口更新事实。 |
| MCP | 展示连接、服务健康、已发现工具、当前授权与最近调用。 |
| Skill | 展示来源、版本、测试、批准、启用或撤回记录，方法的发布和外部工具权限分别治理。 |
| Plugin | 分别回读来源、安装版本、实际兼容类别、启用状态、当前授权、连接健康、可调用能力及管理回执；目录展示、安装成功或登录不等于可执行。 |
| Workshop | 回读任务、依赖、尝试、验收与恢复记录。关闭视图只结束本次展示。 |
| Persona | 展示实际加载的来源与版本，管理个人配置的受控迁移和回滚。 |

Web 与 Mac 应覆盖身份切换、迟到响应、失败草稿、撤权与刷新恢复，并在各自支持的窄屏、暗色或本地窗口布局下核查实际交互。跨身份迟到的结果按原归属留存；授权撤回后，当前视图及时移除受影响的数据。

### 12.4 第三方插件交互界面

插件可以通过开放交互资源（如 MCP Apps）或宿主的原生扩展界面呈现数据及操作。用户不必离开主工作空间。界面绑定所属插件、提供方、工具、会话及相关任务版本，并在相称的隔离边界内呈现；第三方界面不得自行取得宿主凭据、其他会话材料或特权管理接口。

可呈现、可本地交互和可执行业务动作分别核验。生成中 GenUI 的控件按 12.2 处理；独立且已获确认的工具交互资源按其受控界面合同就绪。外部效果的提交经可信宿主核对当前授权、输入和对象版本，取得实际回执。按钮、插件自报完成及连接状态不代替业务权限与证据。已经授权的常规操作不因界面更换而重复审批。

界面退出不证明后台任务停止。停用、撤权、切换会话或更新后，应阻止过时界面继续行使旧资格；迟到回执按原执行事实留存，依据当前授权决定呈现范围。
